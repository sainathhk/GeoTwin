# Prototype (Layer 1, CPU) vs Final (Layer 3, GPU) Mapping

| Layer-1 CPU Prototype | Final GPU Version | Interface Contract |
|---|---|---|
| `synthetic/*` (scene/trajectory/renderer/degradation generator) | *Not replaced* — this is a permanent testing/validation asset, used to regression-test the GPU pipeline too | n/a (test infrastructure) |
| `perception/frame_quality.py` (Laplacian/histogram/DCT classical scoring) | Learned CNN quality regressor (HyperIQA/MUSIQ-style, or custom-trained on this repo's own synthetic degradation pairs) | `i_frame_quality.py` |
| `perception/sensor_fusion.py` (linear KF + complementary-filtered attitude) | Full multiplicative EKF/UKF on SE(3), or GPS/IMU prior refined by visual-SLAM/bundle adjustment (COLMAP-style or learned pose regressor) | `i_pose_estimator.py` |
| `perception/dynamic_object_filter.py` (residual-flow thresholding — measured precision-limited) | Learned video segmentation (SAM2-promptable, or a trained motion-segmentation head); classical mask reused as a weak prompt | `i_dynamic_segmenter.py` |
| `reconstruction/depth_estimation.py` (classical plane-sweep MVS, ZNCC cost) | Learned MVS cost-volume network (MVSNet/CasMVSNet-style) or monocular prior (Depth Anything) fused across views, with a confidence head trained against multi-view geometric consistency | `i_depth_estimator.py` |
| `reconstruction/prototype_point_repr.py` (voxel-merged point fusion) | Per-Gaussian initialization from the same fusion logic (position/scale/opacity/color seeded from fused points) | `i_gaussian_init.py` |
| `reconstruction/confidence.py` (**core novelty**, pandas/numpy) | `layer3_gpu/python/confidence_gaussian_model.py::GaussianConfidenceStats` (CPU-tested PyTorch, identical formula) → `layer3_gpu/csrc/confidence_gaussian/*.cu` (CUDA, same formula, not yet compiled) | `i_confidence_estimator.py` |
| *(no CPU equivalent — see confidence.py's `gate_by_confidence`, generalized)* | `confidence_gaussian_model.py::densify_and_prune` (CPU-tested) → CUDA `gate_densify_prune_kernel` (not yet compiled) — **the actual novel control loop** | `i_gaussian_refine.py` |
| `reconstruction/point_renderer.py` (non-differentiable nearest-point splat, eval-only) | `diff-gaussian-rasterization` (external, unmodified) — differentiable tile rasterizer, used for both training and eval | `i_renderer.py` |
| `reconstruction/occlusion.py` (GT-based coverage diagnostic, eval-only) | *No change needed* — this stays an evaluation-side tool in both layers | n/a (eval infrastructure) |
| `reconstruction/mesh_export.py` (Open3D Poisson/ball-pivoting → `.obj`, confidence/opacity-`keep_mask`-gated) | *No change needed* — operates on plain positions/colors/keep_mask regardless of whether they came from Layer 1's fused points or Layer 3's Gaussian centers (`train_gpu.py::_export_mesh` calls it the same way `run_experiment.py` does); see `docs/ARCHITECTURE.md` §2 for why this doesn't reopen the point-cloud-vs-mesh-vs-3DGS representation choice | n/a (deliverable-format export, not a representation) |
| `evaluation/metrics_visual.py` (PSNR/SSIM real; MS-SSIM proxy; LPIPS NaN-stubbed) | `pytorch-msssim` (real MS-SSIM) + `lpips` (real perceptual metric, needs network access unavailable in Environment A) | n/a (metric library swap, no interface needed) |
| `evaluation/metrics_geometry.py`, `metrics_metric_accuracy.py`, `metrics_completeness.py`, `metrics_efficiency.py` | *No change needed* — these operate on 3-D point coordinates regardless of whether they came from a point cloud or a Gaussian's mean position; same code runs against Layer-3 output | n/a |
| `evaluation/baseline_framework.py`, `ablation_framework.py`, `report_generator.py` | *No change needed*, extended with GPU-baseline configs (COLMAP, real FastGS, NeRF) per `docs/EXPERIMENT_PLAN.md` | n/a |
| *(not implemented anywhere)* | Surface/occlusion completion (learned prior or fitted-primitive completion for partially-seen buildings) — deliberately deferred, see `docs/STOP_CONDITIONS.md` | `i_occlusion_completion.py` |
